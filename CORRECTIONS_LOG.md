# Registro de Correcciones y No Conformidades (Lessons Learned)

> **Instrucción para el Agente:** Antes de proponer cualquier solución o modificar código para corregir un error, DEBES leer este archivo para evitar reintroducir patrones erróneos ya corregidos en este proyecto.

## Historial de Correcciones
| ID | Fecha | Error / Síntoma | Causa Raíz | Solución Implementada / No Conformidad a Evitar |
|---|---|---|---|---|
| 1 | 2026-11-11 | Campo "Otro" de checkboxes/dropdown se cerraba al escribir; error "Objects are not valid as a React child" al escribir en "Quiero autodescribirme" | En FieldRenderer.jsx, el patrón `{ ...fieldValue, [field.id]: fieldValue, ... }` hacía spread de fieldValue (array), creando claves numéricas 0,1,2... que corrompían el objeto de respuestas y hacían que showAdditionalText fuera falso | En FieldRenderer.jsx, cambiar todos los patrones `{ ...fieldValue, [field.id]: fieldValue, ... }` por `{ id: \`${field.id}_other\`, value: e.target.value }`. En FormView.jsx, el onChange de FieldRenderer acepta objetos `{ id, value }` para actualizar solo la clave _other sin corromper el valor principal del campo. |
| 2 | 2026-11-11 | Error "language is not defined" al abrir configuración de campo de género | La función getSameFieldConditionOptions usaba `language` sin estar definida en su scope | Pasar `language` como parámetro a getSameFieldConditionOptions(language) y obtenerla vía `useLanguage()` en ConditionEditor |
| 3 | 2026-11-11 | Error "Cannot read properties of undefined (reading 'hasOptions')" al abrir configuración de campos de texto | La función isTextField accedía a FIELD_DEFS[f.type] sin verificar que existiera, y algunos tipos no tienen entrada | Agregar guard `if (!def) return false;` antes de acceder a def.hasOptions y def.static |
| 4 | 2026-11-11 | Botón "Mostrar si..." no aparecía cuando no había preguntas previas | El componente retornaba un mensaje "Añada antes una pregunta..." y no renderizaba el botón | Eliminar el bloque `if (!prev.length)` y permitir que el botón "Mostrar si..." se renderice siempre, activando "Misma Pregunta" cuando no hay preguntas previas |
| 5 | 2026-11-11 | Select de Valor en "Misma Pregunta" mostraba "Opción 1, Opción 2..." para campos de género, provincia, etc. | El select usaba field.options que para campos como gender no existen; se usaba specialOptionsFor en FieldRenderer pero no en FieldSettings | Crear función getSameFieldConditionOptions(lang) que usa specialOptionsFor para gender, province, education_level y field.options para otros, y usarla en el BuilderSelect de Valor |
| 6 | 2026-11-11 | Campo de texto no mostraba placeholder "Seleccione Valor..." en "Misma Pregunta" | sameFieldCondition se inicializaba con el valor de la primera opción, no vacío | Al activar "Misma Pregunta", establecer sameFieldCondition: "" (string vacío) en lugar del valor de la primera opción |
| 7 | 2026-11-11 | Select de Valor en "Misma Pregunta" mostraba opciones genéricas para campos de texto | Para campos de texto (sin options), se mostraba un select vacío o con opciones incorrectas | Cuando el campo es de texto (isTextField), renderizar un <Input> en lugar de un <BuilderSelect> para el campo de Valor. Para campos con opciones, mantener el <BuilderSelect> con getSameFieldConditionOptions. |
| 8 | 2026-11-11 | Select de Valor en "Misma Pregunta" mostraba select vacío para campos de texto | Cuando el campo es de texto, se renderizaba tanto el <BuilderSelect> vacío como el <Input> de texto | Eliminar completamente el <BuilderSelect> cuando el campo es de texto. Solo mostrar el <Input> de texto para campos de texto libre. Para campos con opciones (radio, checkbox, dropdown, etc.), mantener el <BuilderSelect> con las opciones reales del campo. |
| 9 | 2026-11-11 | Select de Valor en "Misma Pregunta" seguía mostrando <Select> vacío para campos de texto | El condicional isTextField no estaba correctamente aislando los componentes; ambos componentes podían renderizarse simultáneamente | Simplificar el JSX: para campos de texto (isTextField = true), renderizar SOLO <Input>. Para campos con opciones, renderizar SOLO <BuilderSelect>. Eliminar completamente cualquier render de <BuilderSelect> para campos de texto. |
